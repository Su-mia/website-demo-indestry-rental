# منصة كوفراج تونال (عرض تجريبي)

تطبيق React عربي بالكامل (RTL) لمحاكاة منصة كراء الكوفراج التونال ومعدات البناء.

## الميزات
- صفحة رئيسية شاملة مع الأقسام المطلوبة.
- كتالوج معدات مع فلاتر للولاية والنوع والسعر والتوفر.
- صفحة تفاصيل معدة مع إرسال طلب كراء.
- فضاءات المقاول، صاحب المعدات، والإدارة مع بيانات تجريبية.
- إدارة المعدات والطلبات باستخدام حالة محلية و localStorage.

## التشغيل محلياً
1. تثبيت الحزم:
   npm install
2. تشغيل التطبيق:
   npm run dev

## ملاحظات
- البيانات مخزنة في localStorage ويمكن مسحها عبر تنظيف بيانات الموقع في المتصفح.
- لا يوجد backend أو قاعدة بيانات، جميع العمليات تجريبية.
